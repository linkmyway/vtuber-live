# VTuber Live — 多平台直播状态看板

女性人格 VTuber 实时监控看板的实现方法开源版：上百位主播、三平台、按社团分组的实时状态墙是怎么做的。

- 实现文档：[`docs/IMPLEMENTATION.md`](docs/IMPLEMENTATION.md)（双形态直播检测、三平台预览策略、名册策展与链接审计、统一筛选谓词）
- 参考代码：[`reference/`](reference/)（YouTube 双形态解析器、全板统一筛选与热门游戏聚合；`npm install && npm run typecheck` 可直接验）
- 本仓只有方法与脱敏说明；真实名册与直播数据不在本仓（存放在私有存档仓）

一块跨 YouTube、Twitch、Bilibili 的 VTuber 监控板：一份按社团分组的大名册（个人势是一等分组）、一条「正在直播」的 ON AIR 条，以及一个统一的筛选模型（搜索 / 平台 / 社团 / 游戏 / 分类），对名册和直播舞台用同一套规则。

本仓开源的是**实现方法**。所有者的名册与筛选状态存放在私有存档仓；这里的直播检测技术、预览策略与策展纪律才是可复用的部分。

## 有意思的难题

**直播检测是场攻防。** 未登录抓取 YouTube 频道直播页时，经常拿到的是被剥掉播放器数据的机器人校验版页面。天真的解析器会把「没有字段」读成「没在播」，悄悄杀掉大半个看板。解法是双形态解析：有播放器数据就用；落到校验版，就退回页面里还完整的观看人数 / 点赞锚点；两种形态都拿不到锚点，就记为*未知*并重试——解析失败永远不许写成「离线」。

**三平台的预览各不相同，而且如实标注。** 内嵌播放在所有者的真机上失败了，于是卡片改用预览图：Twitch 提供真实的 1280×720 帧（自动刷新）；YouTube 在 159×90 以上没有真实直播帧，卡片就显示本场直播封面，并标明是封面、不冒充直播画面；Bilibili 开播时有房间关键帧。

**策展是审计，不是感觉。** 名册扩容靠逐人核对每个社团的官方成员名单（官方人数 / 已收录 / 新增 / 跳过并注明理由）；频道链接逐个打开审计，比对频道名、handle 与头像是否与卡片一致——这样的审计抓出过普通链接检查会放行的冒充号和占位号。

数据模型、刷新周期、筛选语义与移动端滚动的教训见 [`docs/IMPLEMENTATION.md`](docs/IMPLEMENTATION.md)。
